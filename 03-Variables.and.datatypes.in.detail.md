# Python Variables and Data Types – Complete GitHub Notes
## 1. What is a Variable?

### A variable is a container used to store data values in memory.

### Think of a variable as a labeled box where you can keep information and use it later in your program.

## Syntax
```
variable_name = value
```
#

## Example
```
name = "Shivang"
age = 20
salary = 50000
```
#

## Here:

- name stores a string.
- age stores an integer.
- salary stores a number.
